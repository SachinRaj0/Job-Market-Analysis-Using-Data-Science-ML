# Job Market Analysis Using Data Science and Machine Learning

## Project Overview

This project focuses on analysing job market trends using Data Science and Machine Learning techniques. It explores job distributions across different categories, fresher-friendly opportunities, companies hiring freshers, remote job availability, and the most demanded skills.

The project also implements multiple Machine Learning classification algorithms to predict job categories based on job titles.

## Dataset Source

The dataset is obtained from Kaggle:

**Dataset Name:** Job Listings – Open Jobs in Every Field (Daily)

**Dataset Link:** https://www.kaggle.com/datasets/chandranshbinjola/job-listings/data

The dataset consists of four CSV files:

- `jobs.csv`
- `jobs_by_company.csv`
- `open_jobs_daily.csv`
- `skill_demand_daily.csv`

**Note:** Dataset files are not included in this repository. Download them from the Kaggle link above before running the project.

## Project Objectives

1. Analyse job distribution across different categories.
2. Identify categories offering fresher-friendly opportunities.
3. Analyse companies offering fresher roles.
4. Examine daily open job trends.
5. Identify the most demanded skills.
6. Compare remote and non-remote job listings.
7. Predict job categories using job titles through Machine Learning.

## How to Run the Project

1. Download the dataset from Kaggle.
2. Extract the four CSV files.
3. Place the CSV files in the same folder as the Python script.
4. Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

5. Run the Python file:

```bash
python Job_Market_Analysis_IDLE.py
```
